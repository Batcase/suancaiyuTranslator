fix(android): 修两个真机才暴露的 Bug，并在模拟器上跑通内录

在 MuMu 模拟器（Android 12 / API 32 / x86_64）上真机验证，发现并修复：

1. 【崩溃】后台线程更新 View
   ViewRootImpl$CalledFromWrongThreadException —— 服务里在后台协程直接调用
   SubtitleOverlayView.render()。Android 的 View 只能在创建它的线程上更新，
   结果是整个服务崩溃 → 被 AMS 重启 → 没有 MediaProjection 授权数据 → 停止。
   修复：所有悬浮窗渲染都 Handler.post 到主线程。

2. 【功能缺失】识别引擎失败后不降级
   Paraformer 返回 401 后只记了错误就停住，没有切到下一家。
   翻译层有降级但识别层漏了 —— 与 Windows 端行为不一致。
   修复：按降级链依次尝试；且只在"这家还没成功连上过"时才换，
   避免一次网络抖动就把本来好用的引擎换掉。

新增（排查工具）
- audio/TonePlayer：播放已知响度的正弦波，用来确定性地造出一段声音
- service/SelfTestReceiver + ACTION_SELFTEST：音频自测入口

  内录失败最难查的表现是"界面在跑但没字幕"，而原因可能是三类
  （没声音在放 / 被采集方拒绝 / 采集配置不对）。用自测能把
  "没声音"这个变量排除掉，剩下的才是真问题。
